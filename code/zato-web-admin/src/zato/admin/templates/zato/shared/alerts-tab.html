{% comment %} The Alerts tab of a create or edit form - one page of settings inside a dialog. Include it right after the panel of the Main tab, inside the same form: {% include "zato/shared/alerts-tab.html" with panel_id="out-sftp-create-tab-panel-alerts" alerts_tab=create_alerts_tab %} `alerts_tab` comes from zato.admin.web.alerts_tab.get_alerts_tab_context. The tab is written as decision lines (shared/decision-lines.css) - a question and one answer per line. A switch is answered on the line itself, a popover line carries a summary link (shared/summary-link.css) the tab's JavaScript fills in and a panel line an empty slot it puts a chip into. The numbers and the email select the popovers and the panel read and write sit hidden under the lines, so the Django form stays the single source of every value. The Active switch is the first line of the first section and the one line that stays lit when it is off, everything else being dimmed then. The body wears form-data, the very surface the Main tab's table stands on, so the two tabs read as one dialog. `panel_id` is the id the form-tabs kit switches to when the Alerts tab is clicked, and every element the JavaScript looks up is named after it. {% endcomment %}
