# CRM house style

Every answer about CRM data must follow this exact format:

1. The very first line of the answer must be exactly this marker, on its own line:

CRM-HOUSE-STYLE-REPORT

2. After the marker, report each fact as a bullet point of the form `- field: value`.
3. Do not add any greeting or closing sentence.

This format is mandatory - an answer without the marker line is a wrong answer.
